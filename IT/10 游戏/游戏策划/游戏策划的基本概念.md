游戏策划在实际开发中的基本分类
- **系统策划（System Designer）**
    
    - 设计游戏的整体玩法系统：战斗系统、成长系统、任务系统、经济系统等。
        
    - 举例：在《原神》中设计“体力系统”或“圣遗物强化机制”的人，就是系统策划。
        
- **数值策划（Balance Designer / Game Economist）**
    
    - 负责制定角色属性、装备数值、升级经验、掉落概率等。
        
    - 举例：确定一把武器攻击力多少、一场战斗获得多少金币。
        
- **关卡策划（Level Designer）**
    
    - 负责设计地图、任务、敌人布局、机关谜题等。
        
    - 举例：《塞尔达传说》中设计一个地牢或谜题的策划。
        
- **剧情策划（Story / Narrative Designer）**
    
    - 编写故事、人物对白、世界观设定。
        
    - 举例：《巫师3》的剧情任务或人物分支走向。
        
- **文案策划（Copywriter / Narrative Scriptwriter）**
    
    - 负责文字表现、台词、UI文案、任务提示等。
        
- **执行策划（Game Planner / Producer Assistant）**
    
    - 协调资源、跟进进度、撰写文档、保证策划方案能落地执行。

### ⚙️ 三、游戏策划在开发流程中的位置

游戏开发流程大致是：

1. **立项阶段**：策划提出创意 → 撰写立项文档（Game Concept Doc）。
    
2. **原型阶段**：策划定义玩法 → 与程序、美术合作制作Demo验证可玩性。
    
3. **制作阶段**：策划不断调整数值、关卡、玩法规则。
    
4. **测试与平衡阶段**：策划与QA测试员协作，调整体验。
    
5. **上线与运营阶段**：策划制定活动、平衡更新、版本规划。
    

策划相当于把“创意变成规则”，再交给程序和美术去实现。

### 🧠 四、如果你想成为游戏策划，需要的核心能力

1. **逻辑思维与系统化能力**：能把一个模糊想法拆解成可实现的系统。
    
2. **沟通与表达能力**：能清楚地向程序、美术说明你的设计意图。
    
3. **数据与平衡感**：理解数值如何影响体验。
    
4. **玩家视角**：能从玩家角度判断好玩与否。
    
5. **文档能力**：会写游戏设计文档（GDD）、任务脚本等。
