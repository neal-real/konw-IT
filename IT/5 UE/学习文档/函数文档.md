### SetActorLocation 函数
- 设置任意演员的位置.

### GetActorLocation 函数
- 获取任意演员的位置.

### DeltaTime  Type: float
- 单位是1厘米.  1米就是 (100.0f* DeltaTime)
- 其他类似概念
####  1. `WorldDeltaSeconds`（世界时间增量）

- **类型**：`float`
    
- **含义**：当前世界的时间增量，**与游戏是否暂停无关**。
    
- **用途**：用于**不受暂停影响**的逻辑，比如 UI 动画、背景音乐节奏等。
    
- **获取方式**：
    
    cpp
    
    复制
    
    ```cpp
    float WorldDT = GetWorld()->GetDeltaSeconds();
    ```
    

---

#### ✅ 2. `UnpausedDeltaSeconds`（非暂停时间增量）

- **类型**：`float`
    
- **含义**：**排除暂停时间**的 DeltaTime，**只在游戏未暂停时有效**。
    
- **用途**：用于**角色移动、物理更新**等需要暂停时停止的逻辑。
    
- **获取方式**：
    
    cpp
    
    复制
    
    ```cpp
    float UnpausedDT = GetWorld()->GetUnpausedDeltaSeconds();
    ```
    

---

#### ✅ 3. `TimeDilation`（时间膨胀）

- **类型**：`float`
    
- **含义**：**全局时间缩放因子**，默认值是 1.0。
    
- **用途**：用于**慢动作、快进、暂停**等效果。
    
- **设置方式**：
    
    cpp
    
    复制
    
    ```cpp
    GetWorld()->GetWorldSettings()->SetTimeDilation(0.5f); // 半速
    ```
    
- **注意**：`DeltaTime` 会自动乘以 `TimeDilation`，所以你无需手动处理。
    

---

#### ✅ 4. `FixedDeltaTime`（固定时间步）

- **类型**：`float`
    
- **含义**：**物理引擎使用的固定时间步长**，与帧率无关。
    
- **用途**：用于**物理模拟（如 Chaos 或 PhysX）**，确保物理计算稳定。
    
- **获取方式**：
    
    cpp
    
    复制
    
    ```cpp
    float FixedDT = UPhysicsSettings::Get()->MaxSubstepDeltaTime;
    ```
    

---

#### ✅ 5. `FrameTime`（帧时间）

- **类型**：`FTimespan` 或 `float`
    
- **含义**：**当前帧的总耗时**，包括渲染、逻辑、等待等。
    
- **用途**：用于**性能分析（Profiling）**，不是游戏逻辑常用。
    
- **获取方式**（调试用途）：
    
    cpp
    
    复制
    
    ```cpp
    float FrameTime = FPlatformTime::Seconds() - GStartTime;
    ```
    

---

#### ✅ 6. `GameTime`（游戏时间）

- **类型**：`float`
    
- **含义**：**从游戏开始以来的总时间**，**受 TimeDilation 和暂停影响**。
    
- **用途**：用于**计时器、动画、剧情触发**等。
    
- **获取方式**：
    
    cpp
    
    复制
    
    ```cpp
    float GameTime = GetWorld()->GetTimeSeconds();
    ```
    

---

#### ✅ 7. `RealTime`（真实时间）

- **类型**：`float`
    
- **含义**：**从游戏开始以来的真实时间**，**不受暂停或 TimeDilation 影响**。
    
- **用途**：用于**网络同步、真实计时器、日志记录**等。
    
- **获取方式**：
    
    cpp
    
    复制
    
    ```cpp
    float RealTime = FPlatformTime::Seconds();
    ```

### 移动, 旋转, 缩放
添加旋转的函数
```cpp
FVector 当前位置 = GetActorLocation();
SetActorLocation(当前位置);

AddActorLocalRotation(旋转速度 * DeltaTime)

旋转演员的数据类型: FRotator
移动演员的数据类型: FVector

```
