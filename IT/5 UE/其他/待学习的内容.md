# FluidNinjaLive
> 一款针对实时流体模拟的插件工具，主要用于游戏开发和实时渲染场景，尤其在 Unreal Engine 引擎中应用广泛。
它的核心功能是提供高效、可视化的实时流体效果创作，比如水流、烟雾、火焰等自然现象的模拟。与传统离线流体模拟工具不同，FluidNinjaLive 专注于实时计算，能够让开发者在编辑器中即时预览和调整流体效果

# PCG程序化
常见应用:
1. **游戏开发**
    - 地图/关卡生成（比如《Minecraft》的随机世界，《No Man’s Sky》的星球生态）。
    - 道具、怪物、剧情分支的自动生成。
    - 提高可玩性，减少人工设计成本。
2. **影视与动画**
    - 场景、背景、材质的批量生成。
    - 特效（火焰、烟雾、云层）通过算法随机演化。
3. **建筑与设计**
    - 程序化建模（PCG 建筑/城市布局），快速生成大量建筑群。
4. **音乐与艺术**
    - 算法音乐作曲（AI 辅助的旋律生成）。
    - 纹理、图案的自动生成。
### 特点
- **随机性 + 规则性**：不是完全随机，而是基于规则和参数，保证结果合理。
- **高效率**：能批量生成海量内容。
